# NASA Lost Hardware Archive

A story-driven space exploration game. Play as a young space archaeologist recovering a damaged NASA research archive. Travel to the Moon, Mars, and deep space; investigate the hardware; reconstruct its mission story and science; and restore every file to complete the NASA Lost Hardware Archive.

## Run the game

Open `index.html` in a modern browser. No build step, dependencies, or server are required.

## Gameplay

- Choose a destination to travel to.
- Open each recovered story fragment and use its history and science clues to reconstruct the mission.
- Answer Mission Control's question to restore that mission file.
- Restore all four files to complete the archive. Progress is saved in this browser when storage is available.
- Use the source links on each explorer card to read more from NASA.

The explorers' first-person introductions are imaginative storytelling, not historical quotations. Mission details and status are presented separately and linked to NASA sources.

## Files

- `index.html` — page structure and accessible controls
- `styles.css` — responsive visual design
- `game.js` — mission data, interactions, quiz, and progress
- `.github/workflows/deploy-pages.yml` — publishes the game to GitHub Pages on pushes to `main`
